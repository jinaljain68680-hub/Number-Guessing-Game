# 🎯 Number Guessing Game in C++

A simple, interactive console-based Number Guessing Game written in C++.

## 📝 Description
In this game, the computer randomly selects a number between **1 and 100**. The player's goal is to guess the correct number. After every guess, the program provides feedback on whether the guess was **too high** or **too low** until the player finds the exact number.

## 🛠️ Key Concepts Applied
- **Random Number Generation:** Using `rand()` and `srand(time(0))`.
- **Control Flow:** Using `do-while` loops to repeat until the correct answer is provided.
- **Conditional Logic:** Implementing `if-else` branching to direct game feedback.
- **Basic Console I/O:** Reading input and printing outputs using standard streams (`cin`, `cout`).
